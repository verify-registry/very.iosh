# الملفات المرجعية والأرشيفية

المحتويات هنا محفوظة للمقارنة والتشخيص فقط، ولا يتم تحميلها من `index.html` في التشغيل المعتاد.

- `original-capture/`: ملفات HTML والموارد التي تم حفظها من الصفحة الأصلية.
- `legacy-assets/`: ملفات JavaScript وCSS القديمة أو غير المستخدمة حاليًا، إضافة إلى نسخة واحدة من `webfont.js` المكرر.

لا تنقل هذه الملفات إلى مسار التشغيل النشط إلا عند الحاجة، وبعد تحديث المسارات واختبار الصفحة.
